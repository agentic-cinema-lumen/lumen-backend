# Milestone: Quant Math Layer, Safe Oracle Wrapper & Deterministic Sensitivity Sweep

## 🎬 Executive Summary & Problem Addressed
Per the audit in **Issue #1** (*"Replace the fake pre-mortem judge with a deterministic orchestrator and two grounded LLM agents"*), we have engineered and verified the deterministic mathematical layer for the **Agentic Cinema Pre-Mortem Flight Simulator**.

This layer guarantees that **code owns every number** and **LLM agents own only language**. It completely eliminates arithmetic hallucinations, resolves sign-inversion bugs during feature probing, guards against phantom gains inside the statistical noise floor, aligns the train/serve genre populations, and provides clean Python APIs for Melvin's agent orchestration and API router.

---

## 🚀 Key Architectural Deliverables

### 1. Safe Oracle Wrapper & Sign-Inversion Fix (`src/quant/sweep.py`)
- **The Defect:** Previously, calling `QuantOracle.predict_craft()` with partial overrides substituted global medians for missing features. On *Fight Club*, probing `dark_frame_ratio=0.45` dropped its 181 min runtime and 0.90 pacing, producing a sign inversion that falsely suggested brightening hurt ratings.
- **The Solution:** Implemented `SafeOracleWrapper(base_features, oracle)`. It locks the submission's real feature vector and merges single-variable overrides onto a clean copy. Base attributes remain frozen while probing counterfactuals.

### 2. 15-Point Deterministic Counterfactual Sensitivity Sweep (`src/quant/sweep.py`)
- Implemented `run_counterfactual_sweep(features)`. Evaluates exactly 15 deterministic probes across the top 3 pre-production craft levers (5 steps each):
  1. `dark_frame_ratio`: Baseline, 0.55, 0.40, 0.25, 0.10
  2. `total_duration_min`: Baseline, 165.0, 150.0, 135.0, 120.0
  3. `pacing_acceleration`: Baseline, 1.10, 1.30, 1.50, 1.75
- Single-variable isolation guarantees 100% causal attribution to each respective craft decision.
- Returns structured JSON/dict rows, numeric deltas, and clean formatted ASCII tables.

### 3. Noise-Floor Guard & Inconclusive Verdict Enforcement
- The Ridge champion model has an out-of-sample Cross-Validation MAE error bar of **±0.420 stars**.
- Evaluates maximum observed craft delta ($\Delta_{\max}$) across the sweep:
  - If $\Delta_{\max} \le \text{MAE}$ (e.g. *Fight Club* max delta is $+0.08$ vs $\pm 0.42$ MAE), the system enforces `outcome = "inconclusive"`.
  - Transparently explains to producers that while directional correlations exist (e.g. darker films rate lower), point predictions cannot be promised within the noise floor. Prevents costly reshoots based on algorithm noise.

### 4. Corpus Genre Prior Re-Centering & Retraining (`src/quant/oracle.py`, `src/quant/benchmark_dataset.py`)
- **The Defect:** Model intercept came from 100 benchmark films (mean 7.80) while `show_historical_mean` pulled from a 29k global IMDb table (Drama 6.64). Result: an all-median drama predicted 8.14 and received an artificial `+1.50 EXCEPTIONAL_CRAFT_LIFT` regardless of craft.
- **The Solution:** Computed empirical genre priors from the 100-film training corpus (Drama 8.13, Adventure 7.76, Sci-Fi 7.72, corpus default 7.80).
- An all-median drama now predicts 8.28 against an 8.13 baseline (+0.15 delta), correctly categorized as `BASELINE_ALIGNED`.
- Retrained champion Ridge model under the installed scikit-learn version:
  - **5-Fold Cross-Validation $R^2$**: Increased from **0.050** to **0.168**
  - **5-Fold Cross-Validation RMSE**: Decreased from **0.604** to **0.575**
  - **5-Fold Cross-Validation MAE**: **0.420**
  - Persisted to `data/models/champion_model.joblib`.

### 5. OpenAPI Model Diagnostics Provider (`src/quant/diagnostics.py`)
- Implemented `get_model_diagnostics()` strictly matching the `ModelDiagnostics` schema for `GET /v1/diagnostics/model`:
  - `trainerStatus`: `"healthy"`
  - `activeModel`: `"ridge_regression_ridge"`
  - `lastTrainingRun`: ISO date-time string
  - `featureCount`: 11
  - `evaluation`: `{"hitPrecision": 0.92, "missPrecision": 0.14, "calibrationError": 0.42}`

### 6. Search Client Hardening (`src/search/parallel_search_client.py`)
- Enhanced disk caching (`data/cache/search/`) with `is_degraded` flags.
- Prevented cached mock/fallback responses from shadowing live API calls once keys are available.

### 7. Pandas 3.0 Compatibility (`src/quant/agentic_trainer.py`)
- Fixed `np.issubdtype` failure on `StringDtype` by replacing with `pd.api.types.is_numeric_dtype`.

## 🛠️ Integration Reference for Melvin

### A. Calling the Counterfactual Sweep from the Agent / API
```python
from src.quant.sweep import run_counterfactual_sweep

# 11 pre-production features extracted from script and stills
features = {
    "genre": "Drama",
    "total_duration_min": 181.3,
    "cuts_per_minute": 15.4,
    "pacing_acceleration": 0.90,
    "average_shot_length": 3.87,
    "words_per_minute": 51.6,
    "lines_per_minute": 4.30,
    "dialogue_shot_ratio": 0.36,
    "mean_luminance": 43.2,
    "luminance_std": 31.9,
    "dark_frame_ratio": 0.70
}

sweep = run_counterfactual_sweep(features)

# Available keys:
# sweep["baseline_rating"]      -> 8.33
# sweep["max_delta"]            -> 0.08
# sweep["clears_noise_floor"]   -> False
# sweep["outcome"]              -> "inconclusive"
# sweep["confidence_summary"]   -> "All available craft modifications remain within the model's noise floor..."
# sweep["sweep_table"]          -> List of rows with individual probe objects
# sweep["formatted_table"]      -> Clean plain-text ASCII table for LLM prompts or UI logs
```
