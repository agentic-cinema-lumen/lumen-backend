# Milestone: Production-Ready Quant ML Model & Zero-Leakage Cinema Benchmark

## 🎬 Executive Summary & Vision
Built and hardened the **Quantitative ML Engine & Oracle** for the **Agentic Cinema Pre-Mortem Flight Simulator**. The system evaluates unfilmed screenplays and visual moodboards to forecast expected IMDb audience reception, isolate craft residuals ($\text{Rating}_{\text{actual}} - \text{Rating}_{\text{expected}}$), and detect production vulnerabilities (darkness compression crush, third-act pacing collapse, dialogue fatigue) before physical production begins.

---

## 🚀 Key Achievements & Technical Milestones

### 1. 100% Genuine Cinema Dataset (Zero Synthetic Data)
- Completely deleted all synthetic placeholder images and synthetic data generation scripts (`generate_synthetic_corpus`, `mock_keyframe_generator.py`).
- Curated and validated **100 complete feature film packages** in `data/movies/` (cataloged in `data/movies_100_checklist.md` and `data/movies/movies_manifest.json`).
- Downloaded **752 authentic high-definition widescreen cinematic stills** directly from Film-Grab chronologically spaced across 6 narrative beats ($0\%, 20\%, 40\%, 60\%, 80\%, 100\%$).
- Pruned obsolete directories (`data/real_stills`, `data/sample_scripts`, `data/space`, `data/vikings`).

### 2. Elimination of Target Leakage
- Stripped post-release popularity proxies (`log_votes`) and broadcast scheduling markers (`season_position`, `is_premiere`, `is_finale`).
- Model is strictly grounded in pre-production observable craft metrics:
  - Screenplay Pacing: `total_duration_min`, `cuts_per_minute`, `pacing_acceleration`, `average_shot_length`
  - Spoken Dialogue: `words_per_minute`, `lines_per_minute`, `dialogue_shot_ratio`
  - Keyframe Vision: `mean_luminance`, `luminance_std`, `dark_frame_ratio`
  - Prior Anchor: `show_historical_mean` (empirical genre expectation across 29,374 IMDb films)

### 3. Champion Model Architecture & Benchmark Performance
- Champion: **Ridge Regression** ($\alpha=10.0$) with `StandardScaler` pipeline.
- **5-Fold Cross-Validation MAE**: **0.441 IMDb points** (predictions hold within $\pm 0.44$ stars out-of-sample).
- **5-Fold Cross-Validation RMSE**: **0.604**.
- Empirical Craft Attribution Weights:
  - Genre Baseline Anchor: **41.7%**
  - Screenplay Pacing & Climax Acceleration: **18.1%**
  - Keyframe Cinematography & Lighting Exposure: **16.5%**
  - Runtime Scope: **16.2%**
  - Spoken Dialogue Dynamics: **7.6%**

### 4. QuantOracle: Decoupled Instant Agent Tool
- Champion model persisted to `data/models/champion_model.joblib` (2.7 KB).
- Implemented `QuantOracle` in `src/quant/oracle.py` (`get_oracle()`):
  - **Cold Start**: $<1$ ms load time.
  - **Inference Latency**: **0.54 ms per prediction** (>1,800 predictions/sec) with zero retraining and zero cloud API delay.
  - **Cinema Benchmark Defaults**: Automatically fills missing parameters with cinema medians, guaranteeing zero crashes.
  - **Rule-Based Vulnerability Detection**: Flags severe darkness ($>35\%$), climax spikes ($>1.75\times$), climax deceleration ($<0.75\times$), and verbal velocity deficits ($<30$ WPM).
  - **Point Attributions**: Computes exact star impacts ($\pm \text{pts}$) per feature for agent explainability.
  - **LLM Function Calling**: `oracle.get_tool_spec()` provides standard JSON Schema for Gemini, Claude, OpenAI, or MCP tool arrays.

### 5. Decision History & Explainability Artifacts
- `data/models/ml_decision_history.md` (and `src/quant/DECISION_HISTORY.md`): Detailed chronological log of all engineering decisions, tournament results, and craft theory.
- Exposed via `oracle.get_decision_history()`, `oracle.get_decision_summary()`, and CLI `python scripts/run_model.py --decision-history`.
- Created high-level plain-English overview: `ELI5.md`.
- Created developer guide: `src/quant/README.md`.
